# Конструктор прошивок Kiwiki

Этот инструмент предоставляет графический пользовательский интерфейс (GUI) для легкой настройки и компиляции прошивки Kiwiki.

## Инструкции для Windows 10/11

Для использования этого инструмента в Windows необходимо выполнить несколько предварительных условий.

### 1. Установка необходимых компонентов

#### а) Python 3
Сам инструмент является скриптом Python.
1.  Загрузите установщик Python с официального сайта: [python.org](https://www.python.org/downloads/windows/)
2.  Запустите установщик. **Важно:** В первом диалоговом окне установщика установите флажок **"Add Python to PATH"**. Это крайне важно, чтобы вы могли легко вызывать Python из командной строки.
3.  Следуйте остальным инструкциям установщика.

#### б) GNU Arm Embedded Toolchain (`arm-none-eabi-gcc`)
Это компилятор, который переводит код прошивки на C в исполняемый файл для микроконтроллера.
1.  Загрузите набор инструментов с веб-сайта Arm. Ищите последнюю "кросс-компилятор для Windows x86_64" (в виде `.zip` файла): [Загрузки Arm GNU Toolchain](https://developer.arm.com/tools-and-software/open-source-software/developer-tools/gnu-toolchain/gnu-rm/downloads)
2.  Распакуйте файл `.zip` в выбранный вами каталог, например, `C:\Program Files\arm-gnu-toolchain`.
3.  Добавьте каталог `bin` набора инструментов в системную переменную PATH. В меню "Пуск" Windows найдите "Изменить системные переменные среды", нажмите "Переменные среды...", выберите `Path` в разделе "Системные переменные", нажмите "Изменить...", нажмите "Создать" и добавьте путь, например, `C:\Program Files\arm-gnu-toolchain\bin`. Подтвердите все окна, нажав "OK".

#### в) Make
`make` — это инструмент, который управляет процессом компиляции.
Самый простой способ установить `make` в Windows — через менеджер пакетов [Chocolatey](https://chocolatey.org/).
1.  Если у вас еще нет Chocolatey, установите его, следуя инструкциям на веб-сайте (обычно это команда, выполняемая в PowerShell с правами администратора).
2.  Откройте PowerShell от имени администратора и выполните следующую команду:
    ```sh
    choco install make
    ```
    Кроме того, вы можете установить `make` как часть [Git for Windows](https://git-scm.com/download/win) или [MSYS2](https://www.msys2.org/).

### 2. Запуск инструмента

После установки всех необходимых компонентов вы можете запустить Конструктор прошивок:

1.  Откройте командную строку (`cmd.exe`) или PowerShell.
2.  Перейдите в каталог этого проекта с помощью `cd`.
    ```sh
    cd путь\к\вашему\проекту
    ```
3.  Запустите скрипт Python:
    ```sh
    python designer.py
    ```

Должно открыться окно "Конструктор прошивок Kiwiki". При запуске инструмент проверяет, можно ли найти `make` и `arm-none-eabi-gcc`, и отображает их статус.
